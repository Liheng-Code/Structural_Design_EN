# Excavation Support Design Plan — Sheet Pile and CBP Options

## 1. Purpose and status

This plan defines the engineering workflow for temporary excavation support using either a steel sheet-pile wall or a contiguous bored-pile (CBP) wall.  It is based on the project master prompt and is intended to produce a traceable design package and construction-stage plan.

**Status: PROVISIONAL — NOT A CONSTRUCTION DESIGN.** No excavation depth, ground model, groundwater levels, adjacent-asset survey, surcharge, wall alignment, or project design-basis factors have been provided.  A wall type, pile section/diameter, embedment, support arrangement, and PASS/FAIL conclusion must therefore not be selected from this document alone.

## 2. Design objective

Provide a retaining and groundwater-control system that maintains:

- excavation face stability during every installation and excavation stage;
- adequate embedment and passive resistance, allowing for the declared design approach and any justified passive-resistance reduction;
- structural resistance of the wall, capping beam, walers, anchors or struts;
- acceptable movements of nearby buildings, roads, utilities and services;
- resistance to basal heave, uplift, piping/seepage and global instability; and
- safe formation conditions for base-slab or foundation construction.

The governing situation is expected to be a temporary construction stage.  Permanent and rainy-season/flood cases must also be assessed when relevant.

## 3. Design basis to be confirmed

| Item | Required decision / input | Status |

| Design approach and partial factors | Explicit schedule of action, material, resistance, water and passive-resistance factors | Input required |

Project-specific factors must be labelled as **“Value supplied by project design basis”**. They must not be presented as default Eurocode values.

## 4. Information required before detailed design

1. **Geometry and interfaces:** site survey; excavation plan and sections; formation level; retained ground levels; phased excavation depths; clearances; finished structure/base-slab sequence; adjacent foundations, basements, roads and utilities.
2. **Ground investigation:** boreholes/CPTs across and beyond the excavation; logged strata; laboratory and in-situ tests; representative characteristic/design parameters for each geotechnical unit. Include unit weight, drained friction/cohesion, undrained strength where relevant, stiffness, permeability, OCR and rock data if encountered.
3. **Groundwater:** monitoring wells/piezometers; retained and excavation-side piezometric levels; seasonal maximum, flood level, perched water and proposed drawdown method.
4. **Actions:** permanent loads, construction plant, stockpiles, traffic, crane/outrigger loads, adjacent foundations and any line/point loads within the zone of influence.
5. **Constraints:** noise/vibration limits, access and headroom, spoil and plant space, water-control discharge route, contaminated soils, utilities, working-hour limits and allowable damage criteria.
6. **Structural inputs:** sheet-pile manufacturer properties and steel grade, or CBP concrete/reinforcement grades, cover, pile diameter, spacing, length and capping-beam/support connection details.

The existing borehole-data file should be checked and converted into a ground model; raw SPT/CPT values are not automatically design parameters.

## 5. Preliminary support-system options

### Option A — Steel sheet-pile wall

Use where driving/vibratory installation is acceptable, a relatively continuous wall and water cut-off is beneficial, and access allows handling of pile lengths.  Select only verified manufacturer section properties after allowing for corrosion/design life where required.

Typical arrangement: guide frame → drive piles to approved toe level → install capping beam/waler where required → excavate in lifts → install anchors/struts at the designed stage → construct base → remove or retain temporary supports to the agreed sequence.

Key design issues: installation refusal/obstructions, vibration, interlock integrity and leakage, driving tolerance, section bending/shear/combined action, toe embedment, and extraction effects if piles are temporary.

### Option B — Contiguous bored-pile (CBP) wall

Use where vibration control, variable ground/obstructions, close proximity to sensitive assets, or drilled construction is favoured.  CBP must be modelled as a spaced-pile system unless the justified geometry and method establish equivalent continuous-wall behaviour.  The spaces between piles are not automatically watertight.

Typical arrangement: survey and set out → construct guide wall/working platform → bore and concreted piles to sequence → trim pile heads and construct capping beam → excavate in controlled lifts → install walers/anchors/struts at designed levels → construct base → complete permanent works and agreed support removal/retention.

Key design issues: pile verticality, actual clear gap/overlap, soft-ground loss, bore stability, concrete continuity, reinforcement cage tolerance, capping-beam load transfer, seepage through gaps, and pile-by-pile/equivalent-wall lateral stiffness.

### Selection gate

Choose the preferred system only after comparing both options against the ground model, water-control need, movement limits, nearby structures, installation constraints, programme, cost and maintainability.  Where water exclusion is critical, a CBP wall may need an additional cut-off or grouting solution; this requires separate verification.

## 6. Analysis and verification plan

For each feasible option, carry out the following in one consistent design basis.

| Area | Required work | Required output |
|---|---|---|
| Ground model | Establish engineering layers and characteristic/design parameters with confidence and source | Ground-model section and parameter register |
| Earth and water pressures | Calculate effective stress, active/at-rest/passive pressures, surcharge and separate pore-water pressure | Pressure diagrams, resultants and centroids |
| Structural model | Start with transparent limit-equilibrium checks; use beam-on-elastic-foundation/Winkler model where movements/support stiffness govern | Model assumptions, reactions, moment/shear/deflection envelopes |
| Embedment | Equilibrium of active, water, surcharge and reduced design passive effects | Required/provided toe level and utilization |
| Supports | Design anchor/strut/waler/capping beam and connections for stage actions | Support demand, resistance, stiffness and utilization |
| Wall section | Sheet-pile steel checks to EN 1993, or CBP flexure/shear/axial/N–M/reinforcement checks to EN 1992 | Demand/resistance/utilization and detailing schedule |
| Geotechnics | Basal heave, uplift, piping, seepage, global/deep-seated stability and adjacent-ground response | Check matrix with PASS/FAIL/NOT VERIFIED |
| Serviceability | Wall deflection, settlement and predicted effect on adjacent assets | Movement comparison against project criteria |
| Execution | Constructability, installation tolerances, dewatering and observational method | ITP, hold points and monitoring plan |

For layered soil, non-level ground, wall friction, significant water differential, seismic action, complex surcharge or staged support, do not rely solely on a simple Rankine calculation.  Any simplified method must state why it is appropriate.

## 7. Mandatory construction stages

The final model must run each stage separately and identify the governing stage.

1. Establish survey controls, working platform, utility protection and baseline monitoring.
2. Install sheet piles or CBP wall to the verified toe level; verify line, level, verticality and integrity.
3. Construct capping beam and, if used, install first waler/support at the designed elevation.
4. Excavate in controlled lifts to the next support level; maintain stated groundwater regime and prohibit unmodelled stockpiles/plant at the crest.
5. Install and proof-test anchors, or install/preload struts, before excavating below the support level.
6. Repeat excavation/support stages to formation level; inspect the exposed wall, water ingress and ground movements at every lift.
7. Verify formation, dewater safely and construct the base slab/foundation in the approved sequence.
8. Transfer loads to permanent works; remove, de-stress or leave temporary supports only under a separately checked sequence.
9. Backfill, reinstate drainage and complete final monitoring/close-out.

No change in excavation depth, water level, loading, support level or construction sequence is permitted without assessing its effect on the relevant construction-stage model.

## 8. Water management and rainy-season controls

- Treat pore-water pressure as an independent action; do not double-count water by also using saturated effective unit weight incorrectly.
- Maintain separate retained-side and excavation-side water levels in every stage.
- Provide surface run-off diversion, crest protection, lined sumps and controlled pumping/discharge where dewatering is approved.
- Assess differential head, base uplift, piping and local erosion.  Pumping must not induce unacceptable settlement outside the excavation.
- Suspend excavation and inspect the works following intense rainfall, flood warning, unusual water inflow, loss of ground or monitoring trigger exceedance.
- Include heavy-rain, flood and rapid-drawdown cases where site conditions make them credible.

## 9. Observational method, inspection and hold points

Set project-specific alert and action thresholds before work starts. Suggested instruments, subject to risk assessment, are inclinometers at representative wall locations, settlement markers, survey targets on nearby assets, piezometers, strut load cells and anchor load records.

| Hold point | Release condition |
|---|---|
| Before installation | Approved IFC design, verified ground/water data, utility clearance, working platform and baseline readings |
| After wall installation | As-built toe/line/verticality and integrity records accepted; deviations assessed |
| Before each excavation lift | Previous monitoring readings within limits; supports installed/preloaded/proof-tested as applicable |
| At formation | Inspection confirms stable base, water-control performance and no distress requiring design review |
| Before support removal | Permanent load path and revised-stage verification accepted |

Trigger exceedance requires the predefined response: stop affected excavation/loading, stabilize and control water, notify the temporary-works/geotechnical designer, inspect, and resume only after written release.

## 10. Deliverables and acceptance criteria

The issued package will comprise:

- design-basis register and assumptions log;
- ground model, borehole/CPT interpretation and parameter schedule;
- plan, typical sections, wall/support layout and construction-stage drawings;
- sheet-pile or CBP calculation report showing input → equation/method → result → verification;
- separate ULS, SLS, hydraulic, global-stability and execution check matrix;
- wall/support reinforcement or section schedule and capping-beam details;
- dewatering, monitoring, inspection-and-test and emergency-response plans;
- as-built records and close-out report.

Each check is reported as **PASS**, **FAIL**, or **NOT VERIFIED**.  Missing ground, water, section-property or project-factor data remains **NOT VERIFIED**, never PASS.

## 11. Next action

Develop a site-specific concept design after the information in Section 4 is provided.  The first design submission should compare the two wall systems at the governing construction stage and state the selected option, required embedment, support scheme, predicted movement, water-management provisions and all outstanding verification items.
